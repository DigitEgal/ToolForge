# ToolForge Frontend V1.4

React / TypeScript / Vite. Die gebaute Oberfläche unter `dist` wird vom Backend ausgeliefert.

Neu in V1.4: Übergabe- und Prüferauswahl im Vorabcheck und im Cockpit, optionaler Vorabcheck, vollständige EN/DE-Oberfläche mit Sprachumschalter, vier lokalisierte Tutorials und klarere Docker-Daemon-Fehler. Neu in V1.3: Modellquelle OpenCode Free mit bewussten Modellquellen-Presets, konfigurierbarer Reihenfolge und erlaubter Modelle, wiederholbarer Vorabcheck, klarere Pilot-Startschaltfläche sowie Einstellungen für Top-p und kleine Modelle. Das Frontend bleibt in V1.2-Optik mit verzögert geladenen Bereichen und cachebaren Assets.

Entwicklung: `npm ci`, `npm run dev` (Port 5173, API-Proxy auf Port 8000).
Prüfen und bauen: `npm run build` (TypeScript-Prüfung eingeschlossen).
Für normalen Windows-Start ist Node.js nicht erforderlich. Siehe README im Projektstamm.
